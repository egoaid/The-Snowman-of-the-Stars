星の雪だるまについて

雪だるまが暮らす3Dの自然を舞台にした、ブラウザで遊べる箱庭アプリです。歩行モードで自分で歩く、見守りモードで雪だるまの暮らしを眺める、編集モードで丸太などを動かす、の3つの遊び方があります。昼夜・季節・天候が変わり、環境音はすべてその場で生成されます。ユーザーとワールドを作って、ワールドごとにこの端末のブラウザ内へ保存できます。無料で、インストールは不要です。スマートフォンにも対応しています。

操作方法

PC
WASD: 移動 / マウス: 視点 / Space: ジャンプ / Shift: 走る(押している間)
V: 視点切替(一人称・三人称) / E: インベントリの開閉 / 1〜9・ホイール: ホットバー選択
左クリック: 狙っている物へアクション / Esc: 歩行モードを終える

スマートフォン
画面左のジョイスティック: 移動 / A: ジャンプ / B: 走る(押している間)
👝: インベントリの開閉 / ✦: 狙っている物へアクション / 画面右上の✕: 歩行モードを終える
ホットバーのアイコンをタップ: 持つ物を選ぶ

環境音は川・雨・風・虫・鳥・焚き火・雷、効果音は足音・拾う/置く・チェスト・丸太・星の鈴の音です。
動作が重い端末では「標準」か「オフ」にしてください(⚙️のデバッグ表示でFPSを確認できます)。
🌦️ 天候・季節
「自動」では梅雨に雨が増え、台風シーズンに雷雨が増え、冬は雪になるなど、 季節ごとに天候の傾向が変わります。
